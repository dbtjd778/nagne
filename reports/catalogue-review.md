## 접속 확인 결과와 범위

초기 206개 목록부터 검사한 뒤, 설명을 고친 기존 항목과 새 항목을 합쳐 588개 후보를 점검했습니다. 기본 주소에서 실패한 공식 사이트는 `www` 호스트를 추가 확인했으며 13개를 정상 주소로 교정했습니다.

최종 500개 중:

| 확인 방식 | 항목 수 | 결과 |
| --- | ---: | --- |
| HTTPS GET, 리디렉션과 응답 본문 검토 | 495 | 정상 응답 |
| 실제 브라우저에서 공식 페이지 렌더링 확인 | 5 | Neal.fun, Canva, Khan Academy, ChatGPT, Claude |

5개 사이트는 자동 요청에 접근 제한을 반환했으므로 `linkStatus: "restricted"`를 그대로 남겼습니다. 브라우저 확인 결과는 `browserVerifiedAt`와 보고서의 `browserVerification`에 별도로 기록했습니다. Claude는 공식 로그인 안내 화면까지 확인했습니다.

이는 홈페이지와 시작 화면의 접속 확인입니다. 회원가입·로그인·결제와 모든 내부 기능을 시험했다는 뜻은 아닙니다. 지역, 계정, 기기와 사이트의 운영 변경에 따라 실제 이용 범위는 달라질 수 있습니다. 구름EDU는 응답 크기 제한 2MiB에 도달했지만 정상 HTTP 상태와 공식 페이지 제목을 확인했습니다.

가이드 6편에 포함된 정확한 추천 URL 24개도 별도 검사했습니다. 21개는 정상 HTTP 응답, 나머지 3개(Neal.fun, Canva, Khan Academy)는 위의 실제 브라우저 확인으로 보완했습니다.

## 제외와 교정

- DNS 실패, 404, 410, 반복 접속 실패 항목은 최종 목록에서 제외했습니다.
- 리틀리(410), 사라진 개인 GitHub Pages 2개(404), 잘못된 도메인·만료 가능성이 있는 작은 도구를 정리했습니다.
- 백준은 HTTP 200을 반환하지만 실제 제목이 **“BOJ 서비스 종료”**여서 제외했습니다. 정상 상태 코드만으로 살아 있는 서비스로 판단하지 않았습니다.
- Glitch는 기존 개발·호스팅 서비스 대신 블로그로 연결되어 제외했습니다.
- 챌린저스는 기존의 습관 형성 설명과 현재 서비스 목적이 달라 제외했습니다.
- 도다는 스모어로 연결되어 중복 항목으로 제외했습니다.
- 무작위 외부 사이트 이동 서비스, 출처를 확인하기 어려운 개인 페이지, 익명 질문 서비스 등은 이번 큐레이션에서 제외했습니다.
- Vrew, Notion, Runway, v0, 마이루틴 등 주소가 바뀐 서비스는 정상 주소로 수정했습니다.
- 공식 리디렉션과 페이지 제목에 맞춰 국가데이터처, 기후에너지환경부, Global Nature Watch 등 현재 명칭을 반영했습니다.
- “가장 정확한”, “모든 기능 무료”, “저작권 없는” 같은 검증되지 않은 최상급·무제한 이용 표현을 제거했습니다. 글꼴·사진·음원은 자료별 이용 조건을 확인하도록 설명했습니다.

성인·도박·불법 복제·무작위 리디렉션 모음 사이트를 추가하지 않았습니다. 소개는 각 공식 서비스의 용도를 바탕으로 이 목록을 위해 작성했습니다.

## 아이콘 처리

공식 HTML에 선언된 아이콘 URL, 동일 공식 호스트의 표준 favicon 경로, 실제 브라우저 DOM에서 확인한 경로만 사용했습니다. 원본 URL을 각 검사 결과의 `iconSource`에 남겼습니다. 제3자 favicon 프록시에 방문자 정보를 보내지 않습니다.

저장한 아이콘은 모두 최대 64px의 정적 WebP로 변환했습니다. 스크립트·이벤트 속성·외부 참조 등이 있는 SVG는 거절했고, 원본 SVG·ICO·PNG는 배포용 아이콘 디렉터리에 남기지 않았습니다. Neal.fun은 실제 공식 DOM의 `/favicons/home.png`를 확인해 브랜드 아이콘을 확보했습니다. ChatGPT의 공식 아이콘은 별도 정적 URL도 자동 요청을 차단하여 문자 표식을 사용합니다.

선택된 473개 아이콘의 합계는 485,684바이트(약 474KiB), 가장 큰 아이콘은 3,674바이트입니다. 모든 파일의 실제 디코딩과 크기를 검사했으며 선택되지 않은 아이콘은 정리했습니다.
